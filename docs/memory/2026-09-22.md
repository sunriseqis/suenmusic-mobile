## 换源「切了不移、移了半途止声」——原生播放器侧的根因


> 这是原文 §一「四条根因」中的第 2 条；另外三条在服务端与 Web 侧，留在原文。

2. **换源根本没到原生播放器**：`bridge.ts` 里 `audio.src = url` 只记录 `trackId`、**丢弃 URL**，
   `SuenAudioPlugin` 的缓存键是 `setCustomCacheKey(id)`（按曲目 id 落盘），
   而 ExoPlayer 内存里还留着旧 buffer → 「服务端解析换了源，播放器还是旧源」。
   → 原生新增 `reloadCurrent({index, positionMs, autoplay})`：`stop()` 丢内存缓冲 →
   `replaceMediaItem(同 id / 新 URL / 同 cacheKey)` → `prepare()` → `seekTo` → `play()`；
   JS 侧 `reloadNativeSource()` 在锚点切换后调用。
