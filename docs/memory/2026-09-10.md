## 战略定位：安卓是长期需求（决定了后续所有客户端形态）

- 用户明确：**「安卓端是长期需求，网页 / 桌面端不是」**。
- 据此推翻了 YesPlayMusic 路线（Vue2 + Electron 桌面壳）—— 对「服务端 + 安卓 + 多端同步」
  是结构性错配（Electron 下 B 站音频必然 403）。
- 进而定下服务端技术选型（Node + TypeScript），一套后端同时服务两端，不做两套。
- 原文位置：`2026-09-10.md` 的「第三轮：方向反思」与「4.1 服务端立项」。
